# 토마토 키오스크 UI 데모

Figma의 `04-2_상태 및 팝업_휴대폰 회원 [1080×1920]` 페이지 중 `01_Start / 상품 미등록`과 내부 `04_Payment`를 기준으로 만든 GitHub Pages용 정적 데모입니다. 빌드나 패키지 설치 없이 `index.html`을 바로 열어 사용할 수 있습니다.

## 파일 구성

- `index.html`: 1080×1920 키오스크 화면과 접근성 구조
- `styles.css`: 화면·모달·모션 스타일. 속성 하나당 한 줄로 정리됨
- `app.js`: 상품, 장바구니, 회원, 포인트, 결제 시연 로직
- `assets/`: Figma에서 추출한 결제 삽화와 상태 아이콘

## 초기 화면 기준

- 장바구니가 비어 있으면 결제수단과 `결제하기` 버튼이 비활성화됩니다.
- 결제 영역은 Figma와 동일하게 상단 안내·봉투 구매·전체 취소·결제하기, 하단 결제금액·결제수단 구조로 배치했습니다.
- 상품 선택 카드는 별도 이미지 없이 상품명·가격·행사 표시만 사용합니다.
- 회원 정보는 초기 화면에 나오지 않으며, 회원 확인 또는 가입 이후 헤더 오른쪽에 휴대폰 번호와 보유 포인트가 두 줄로 표시됩니다.

## 빠른 시연 순서

1. 오른쪽 `상품 직접 선택`에서 상품을 눌러 장바구니에 담습니다.
2. 화살표나 좌우 스와이프로 8개 카테고리를 이동합니다.
3. 결제수단을 선택하고 `결제하기`를 누릅니다.
4. 테스트 회원은 `010-1234-1234`, 최초 포인트는 `2,000P`입니다.
5. 포인트는 `50P` 단위로 직접 입력하거나 사용 가능 전액을 선택합니다.
6. 신용카드·현금은 3초 뒤 결제 완료, 간편결제는 3초 뒤 승인 오류로 이동합니다.
7. 승인 오류의 `결제수단 변경`에서 카드·간편·현금 중 하나를 다시 고를 수 있습니다.

## 회원 DB

- Chrome에서는 IndexedDB의 `tomato-kiosk-demo / members` 저장소를 사용합니다.
- IndexedDB를 쓸 수 없는 환경에서는 localStorage로 자동 대체합니다.
- 신규 가입 시 해당 브라우저에 회원 번호와 `5,000P`가 저장됩니다.
- 결제에 사용한 포인트는 성공 시 차감되어 새로고침 후에도 유지됩니다.
- 상단 `시연 초기화`에서 화면 상태만 초기화하거나 회원 DB까지 초기화할 수 있습니다.
- 회원 DB 초기화 시 신규 회원이 삭제되고 테스트 회원 `010-1234-1234 / 2,000P`가 복원됩니다.
- 장바구니는 저장하지 않으므로 페이지를 새로 열거나 새로고침하면 항상 빈 상태입니다.

## 화면 크기

디자인 원본은 정확히 `1080×1920`입니다. 브라우저 폭이 1080px 이상이면 축소하지 않고 원본 크기로 표시하며, 가로형 모니터에서는 세로 스크롤로 전체 화면을 봅니다. 브라우저 폭이 1080px보다 좁을 때만 가로 폭에 맞춰 비율 축소합니다.

## 삽화 자산

빈 장바구니, 카테고리 화살표, 결제수단, 카드 리더기, 바코드 스캔, 현금 투입구, 결제 완료·오류 아이콘은 Figma 벡터 노드를 투명 PNG로 렌더링해 로컬 `assets/`에 포함했습니다. 외부 Figma URL을 사용하지 않아 링크 만료나 CORS 문제 없이 GitHub Pages에서 표시됩니다. 카드 리더기는 원본 프레임의 눌려 보이는 세로 비율을 코드에서 보정했습니다. 실제 서비스로 전환할 때는 같은 노드를 SVG로 export하고 현재 `<img>` 경로만 교체하면 됩니다.

## GitHub Pages 배포

ZIP의 내용물을 저장소 루트에 덮어쓴 뒤 커밋하고 푸시합니다.

```bash
git add index.html styles.css app.js assets README.md
git commit -m "Rebuild kiosk demo flow"
git push origin main
```

GitHub Pages가 이미 `main` 브랜치에서 배포되도록 설정되어 있다면 별도 배포 명령은 필요 없습니다. 푸시 후 Pages 빌드가 자동으로 다시 실행되며, 보통 잠시 뒤 기존 URL에 반영됩니다. 브라우저 캐시가 남으면 강력 새로고침을 사용하세요.

## 시연용 추가 편의 기능

- 상품 추가·모달 열림·진행 상태에 짧은 전환 애니메이션 적용
- 물리 키보드 숫자·Backspace·Enter 지원
- 결제 완료 후 8초 자동 초기화와 영수증 선택
- 간편결제 오류 후에도 장바구니·회원·포인트 상태 보존
- 접근성 포커스 표시와 `prefers-reduced-motion` 대응
- 주요 화면 구조는 CSS Grid와 Flexbox로 구성
