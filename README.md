# 상품 이미지

ERP 에서 내려받은 상품 이미지를 이 폴더에 넣습니다.

- 비율은 **1:1 정사각**
- 파일명은 **상품 id** 와 맞춥니다 (`app.js` 의 `PRODUCTS` 참고)
- 확장자는 `jpg` → `png` → `webp` 순서로 찾습니다
- 파일이 없는 상품은 빈 이미지 자리가 그대로 유지되므로 일부만 넣어도 됩니다

예시

```
assets/img/r01.jpg   신라면 블랙 사골곰탕 멀티팩 (4봉)
assets/img/d01.jpg   초정탄산수 플레인 330ml
assets/img/l01.jpg   마이비데 비데 일체형 변좌
```
