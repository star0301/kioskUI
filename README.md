# 토마토 셀프 계산대 프로토타입

Figma `04\_전체 화면 및 플로우` 페이지를 기준으로 만든 GitHub Pages용 정적 시연입니다.
빌드나 패키지 설치 없이 `index.html`을 열면 바로 동작합니다.

## 파일 구성

|파일|내용|
|-|-|
|`index.html`|1080×1920 캔버스 · 헤더 · 장바구니 · 프리셋 · 결제 바 · 모달 루트|
|`styles.css`|디자인 토큰 → 레이아웃(Grid/Flex) → 컴포넌트 → 모달 → 상태|
|`app.js`|CONFIG · DATA · STATE · CART · RENDER · MODAL · SCANNER · INIT|

이전 버전의 `assets/` 폴더는 사용하지 않습니다. 아이콘과 삽화는 모두 인라인 SVG로 그립니다.

## 화면 크기

기준은 `1080 × 1920`입니다. 브라우저 상단 UI 때문에 세로가 200px 정도 모자라도
스크롤 없이 각 영역이 눌리도록 `1720 \~ 1920` 구간을 유연하게 사용합니다.
1720px 미만에서만 세로 스크롤이 생깁니다.

## 운영 옵션

헤더의 **매장명(토마토마트 본점)** 을 누르면 옵션 패널이 열립니다.
설정은 브라우저 `localStorage`에 저장되며 `적용하고 새로고침`을 누르면 반영됩니다.

|옵션|시연 기본값|운영 기본값|
|-|-|-|
|셀프계산대 사용|ON|ON|
|신규회원 가입 금지|OFF|OFF|
|고객적립 사용|ON|ON|
|현금결제 사용|**ON**|OFF|
|연령제한상품 판매불가|OFF|OFF|
|봉투판매 사용|**ON**|OFF|
|타임아웃(초)|0|0|

헤더 왼쪽 **Tomato 로고**를 누르면 시연 기본값으로 되돌립니다.

## 바코드 시연

물리 스캐너는 키보드처럼 동작하므로, 화면에 보이지 않는 입력창에 포커스를 유지하다가
`Enter`가 들어온 시점에 한 건으로 처리합니다. 스캐너가 없으면 키보드로 직접 입력해도 됩니다.

|바코드|결과|
|-|-|
|`8801223100209`|초정탄산수 플레인 330ml · 330원|
|`8801166054966`|마이비데 비데 일체형 변좌 · 35,000원|
|`20250708000115`|APP 회원 갓준경 로그인|
|그 밖의 숫자|미등록 상품 안내|

## 회원

|구분|식별자|포인트|용도|
|-|-|-|-|
|APP|`20250708000115` 갓준경|5,000P|쿠폰 자동 적용 · 포인트 사용|
|휴대폰|`010-1111-1111`|3,000P|포인트 사용|
|휴대폰|`010-0000-0000`|0P|포인트 사용 불가 상태|

위 셋과 겹치지 않는 번호를 입력하면 미가입으로 처리되어 가입 흐름으로 이어집니다.
가입 시 축하 포인트 2,000P가 지급되며 그 결제에 바로 사용할 수 있습니다.

## 쿠폰

APP·휴대폰 로그인 시 자동으로 적용됩니다.

|쿠폰|할인|조건|
|-|-|-|
|농할쿠폰|−5,000원|마이비데가 장바구니에 있을 때|
|가입축하쿠폰|−1,000원|상품이 하나라도 있을 때|
|라면기획전|−500원 × 수량|라면 25개 중 앞 20개|

## 상품

라면 25 · 음료 7 · 냉장 6 · 과자 8 · 생활용품 6 · 주류 6, 모두 58개입니다.

프리셋은 항상 **2열 × 5행** 규격이며 페이지당 10개입니다.
라면은 `10 / 10 / 5`로 나뉘고, 마지막 3페이지는 왼쪽 1열만 채워집니다. 의도된 배치입니다.

주류에 연령제한 4종과 품절 1종이 있어 상품 등록 예외를 시연할 수 있습니다.

## 시연 순서

1. 오른쪽 프리셋에서 상품을 담고 카테고리·페이지를 넘겨봅니다.
2. `8801166054966`(마이비데)을 스캔합니다. 농할쿠폰 대상입니다.
3. 결제수단을 고르고 `결제하기`를 누릅니다.
4. `20250708000115`를 스캔하면 쿠폰 3종이 자동 적용된 화면이 열립니다.
5. `직접 입력`에서 999P를 넣어 실시간 검증을, 1,000P를 넣어 정상 적용을 보여줍니다.
6. 간편결제는 첫 시도에서 승인 거절이 뜨고, 다시 시도하면 완료됩니다.
7. 결제 완료 화면에서 8초 뒤 자동으로 초기화면으로 돌아갑니다.
8. 옵션 패널에서 현금결제·봉투판매를 끄고 화면이 어떻게 달라지는지 보여줍니다.
