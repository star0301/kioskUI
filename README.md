# 토마토 셀프키오스크 UI 시연

Figma `04-2_상태 및 팝업_휴대폰 회원` 페이지를 기준으로 제작한 정적 HTML/CSS/JavaScript 데모입니다.

## 실행

설치 과정 없이 `index.html`을 브라우저로 열면 실행됩니다. 로컬 서버를 사용하려면 프로젝트 폴더에서 아래 명령을 실행합니다.

```bash
python -m http.server 8080
```

그다음 `http://localhost:8080`에 접속합니다.

## 시연 가능한 흐름

- 상품 직접 선택, 수량 증감, 삭제, 봉투 추가, 전체 취소
- 신용카드·간편결제·현금결제 선택
- 기존 회원 휴대폰 번호 확인과 포인트 사용
- 보유 포인트 0P 회원 확인
- 미가입 회원의 번호 재입력·신규 가입·비회원 결제
- 포인트 직접 입력과 10P 단위 오류 안내
- 결제 승인 성공·오류, 결제수단 변경, 재시도
- 영수증 출력 여부 선택과 자동 초기화

## 시연용 휴대폰 번호

- `010 1234 5678`: 기존 회원, 1,243P
- `010 0000 0000`: 기존 회원, 0P
- 그 외 11자리 번호: 미가입 회원
